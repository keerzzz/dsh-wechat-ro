# 使用指南：微信历史、数据卡片与 MCP

本项目面向 Windows、macOS、Linux。下述一键采集步骤对应当前已验证的 Linux 实现；其他平台的实施与验收进度见[平台支持说明](platform-support.md)。

## 1. 准备环境

插件安装、启用、DSH 版本与系统依赖见[安装指南](installation.md)。当前插件为 `0.2.0`，DSH 声明要求 `>=0.2.1-rc.2`；本机验收使用基于 `0.2.1-rc.2` 的扩展宿主。官方原版中尚无当前使用的两项 sealed API，可分发的宿主扩展仍待补齐。独立开发与 CI 使用 Node.js 24.15.0、pnpm 10.34.1、Python 3.12。

一键历史导入当前支持经构建检查的 Linux 微信 4.1.13.26。打开同一台 Linux 电脑上的微信，登录本人账号；首次取钥需要系统 `pkexec` 认证。后台更新复用已经核验的密钥，有新数据才生成副本。

## 2. 连接本人微信机器人

按[安装指南](installation.md#3-在插件管理器安装并启用)在兼容 DSH 环境中安装并启用 `plugin/` 组合包，使用默认 `cordis.patch.yml`。

1. 打开原生会话，选择本地项目目录与模型。
2. 打开「微信」侧栏，点击「扫码连接微信」，用本人手机微信确认。
3. 已有配对时使用「连接微信」。连接按钮确认所选目录、模型处理、配对保存和自动文字回复。
4. 向该机器人发送一条简短查询，检查手机收到回复和 DSH 原生会话中的处理结果。

同一微信入口复用原生会话、模型选择和项目归属。高级设置中的来源、文件回传和恢复操作按各自用途确认。

## 3. 一键导入与更新

在侧栏点击「一键导入微信历史」，核对本人历史与当前任务范围，需要时完成系统认证。导入成功后，微信机器人可按联系人、日期和关键词搜索。

```text
整理李明近 7 天的内容，列出关键事实和原文引用。
搜索今天文件传输助手里的“项目验收”，给出原文和北京时间。
```

历史更新有两种触发：搜索前检查，以及每分钟空闲检查。数据库或 WAL 改变时更新；失败时保留已有合法副本，并显示更新时间或错误。一次模型查询的分页固定使用同一副本代次。

副本与密钥保存在当前桌面用户的私有目录中。Host 重启后重新连接并导入，已有密钥通过核验后复用。

## 4. 每日数据卡片

在设置中选择每天生成卡片的时间，默认北京时间 08:00。侧栏展示指标、近 7 天趋势、消息构成和会话排名，可选择日期查看对应结果。

重点和待办线索通过「群聊 / 个人 / 公众号 / 服务号」页签分开，按来源会话分组，每条保留原文证据。待办线索尚未记录负责人或完成状态。摘要当前采用有界摘录，界面显示覆盖范围。

## 可选只读 MCP

Python 服务读取标准 SQLite 解密副本，目录包含 `contact/`、`session/` 和 `message/`。它提供 8 个工具：

| 工具 | 用途 |
| --- | --- |
| `wechat_status` | 副本状态、数据质量与读取信息 |
| `wechat_contacts` | 联系人查询 |
| `wechat_sessions` | 会话列表 |
| `wechat_messages` | 指定会话消息 |
| `wechat_search_messages` | 关键词搜索 |
| `wechat_timeline` | 时间线 |
| `wechat_chatroom_members` | 群成员 |
| `wechat_sql` | 受只读策略限制的 SQL 查询 |

支持 stdio MCP 的客户端可参考：

```json
{
  "mcpServers": {
    "wechat": {
      "command": "/absolute/dsh-wechat-ro/.venv/bin/python",
      "args": ["-m", "wechat_ro_mcp"],
      "env": {
        "PYTHONPATH": "/absolute/dsh-wechat-ro",
        "WECHAT_SNAPSHOT_DIR": "/absolute/private/snapshot/decrypted"
      }
    }
  }
}
```

将路径替换为实际位置。DSH 专用配置见 [deploy/wechat-ro.cordis.yml](../deploy/wechat-ro.cordis.yml)。

## 验收与常见问题

- 扫码二维码打不开：先检查侧栏连接状态和具体错误；停止后重新连接。保留已存配对，避免直接删凭据。
- 搜索没有新消息：确认桌面微信与 DSH 在同一台电脑、账号一致、历史导入成功，并查看最近副本时间。
- 摘要条数少：查看卡片覆盖范围；有界摘要与完整历史搜索使用不同预算。
- Host 重启后：重新点击连接和导入。自动运行意图目前不跨重启恢复。

一次完整验收可在本人桌面微信「文件传输助手」发送合成标记，再向机器人请求搜索该标记。检查原文、北京时间、记录引用及副本更新时间；同时确认无新消息时空闲检查不会重复生成副本。
